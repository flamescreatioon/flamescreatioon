## 🧩 Featured Projects

### 🌐 AirBridge

Cross-platform local-network file and clipboard sharing system connecting a **native C++ desktop service** with a **Flutter Android application**.

Includes:

- Automatic LAN peer discovery
- UDP broadcast and multicast
- HTTP-based file transfer
- Clipboard synchronization
- Embedded desktop web dashboard
- Windows and Linux support
- Android client
- Transfer progress and file handling

**Stack:** `C++17` `Flutter` `Dart` `HTTP` `UDP` `Networking`

---

### 🚘 Low-Cost License Plate Reader

Computer vision system for detecting and recognizing vehicle license plates.

Features:

- YOLO-based plate detection
- OpenCV fallback detector
- EasyOCR plate recognition
- Image preprocessing
- GPU acceleration
- OCR evaluation pipeline
- FastAPI backend
- SQLite detection logging

**Stack:** `Python` `YOLO` `OpenCV` `EasyOCR` `FastAPI` `SQLite`

---

### 📚 EduVault

Offline-first digital learning server designed for schools with limited or unreliable internet connectivity.

The system can run on low-power hardware and serve educational content to students over a local network without requiring continuous internet access.

**Stack:** `Go` `SQLite` `React` `PWA` `Docker`
